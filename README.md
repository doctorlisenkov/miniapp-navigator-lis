# miniapp-navigator-lis
Telegram Mini App navigator (learning project)

Навигатор по подкастам «Мария Богиня»: 15 сезонов, поиск по эпизодам,
отметка «просмотрено» с сохранением прогресса, интеграция с Telegram WebApp.

## Файлы
- `index.html` — приложение (HTML + CSS + JS в одном файле)
- `data.json` — контент: сезоны и эпизоды (title + ссылка t.me)
- `stars.png` — фон

## Запуск
Открыть `index.html` на любом статическом хостинге (или локально через
http-сервер). Для Telegram — указать URL в @BotFather как Mini App.
